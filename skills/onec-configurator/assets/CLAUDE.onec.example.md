## Работа Claude

Для задач 1С использовать `onec-configurator`. Читать тематические справочники
по необходимости. Режим «только анализ/инструкция» не изменяет файлы и ИБ.
Для реализации делать минимальную достаточную правку и проверять связи.
Не внедрять EDT и не менять структуру проекта ради инструментов скилла.
Для MVP допустим обоснованный небольшой дубль; число общих модулей минимально.

Git pull, загрузка файлов в ИБ и обновление конфигурации БД — отдельные действия.
База для записи должна быть однозначно определена задачей/профилем.
Уже выданные разрешения учитывать, повторных согласований без причины не требовать.
Не менять .gitattributes и окончания строк всего проекта в функциональной задаче.
