# Работа с 1С в этом проекте

Использовать `onec-configurator` для выгрузок Конфигуратора. Сначала определить
корни, платформу и совместимость; затем читать нужный тематический справочник.
Не переводить проект в EDT. Анализ/инструкция означает чтение без изменения ИБ.
Сохранять чужие изменения и делать минимальный diff. Для MVP использовать
существующие модули и точки расширения. Недоступную проверку обозначать not_run.
Git pull не выполняет загрузку в ИБ и обновление БД. Запись направлять только
в определённый пользователем/профилем стенд в пределах поручения.
