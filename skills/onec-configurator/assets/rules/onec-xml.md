# XML выгрузки 1С

Это правило относится к XML метаданных/форм/макетов 1С, не ко всем сторонним XML.
Определить вид и версию формата. Сохранить UUID, типы, namespace, порядок,
идентификаторы элементов и ссылки. Не заменять все UUID при копировании объекта.
Не переписывать дерево целиком ради одной правки. Проверять владельца и
зависимости. XML parse не заменяет XSD/XDTO, загрузку и проверку платформой.
Для форм читать forms.md, для СКД — dcs.md, для структуры — designer-xml.md скилла.
