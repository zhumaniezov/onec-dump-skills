# BSL

Проверять свойства модуля, клиент/сервер, версию API, определения вызываемых
методов и все затронутые сигнатуры. Имена БСП не угадывать. Публичный контракт
документировать; комментарии внутренних методов добавлять по смыслу и правилам
проекта. Сохранять BOM/EOL, не переформатировать весь файл. Для запросов
прочитать queries.md скилла; для записи регистров — registers.md.
Успех BSL LS не равен выполнению кода в 1С.
