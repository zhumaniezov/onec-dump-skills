###### #std464

# Обработчик события ПередЗаписью

###### 1.

В обработчике `#!bsl ПередЗаписью` выполняйте:

- заполнение реквизитов объекта (набора записей, значения константы);
- проверку правильности заполнения;
- проверки связанности состояния объекта с внешними данными;
- работу со «старыми» значениями реквизитов, уже сохраненными в базе.

Этот обработчик особенно полезен при редактировании уже записанных объектов.

###### 2.

Все действия в обработчике `#!bsl ПередЗаписью` выполняйте только после проверки `#!bsl ОбменДанными.Загрузка`.

!!! example "Пример"

    ```bsl
    Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
    
        Если ОбменДанными.Загрузка Тогда
            Возврат;
        КонецЕсли;

        // Предпроверки и дозаполнение реквизитов объекта.
        ...
    КонецПроцедуры
    ```

Проверки: `acc:75`, `bslls:DataExchangeLoading`, `v8cs:data-exchange-load`
