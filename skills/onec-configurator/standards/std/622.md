###### #std622

# Флажки

Флажки используйте
для реквизитов типа `Булево`.

Подписи к флажкам
оформляйте по правилам ниже.

###### 1.

Подпись располагайте
справа от флажка.

<div class="std-good-bad-pair" markdown="1">

!!! success "Правильно"

    *[рисунок «Подпись справа от флажка» — см. ИТС]*

!!! failure "Неправильно"

    *[рисунок «Подпись не справа от флажка» — см. ИТС]*

</div>

###### 2.

Если для флажка нужна подсказка,
ее располагайте
либо снизу,
либо справа от подписи.

<div class="std-good-bad-pair" markdown="1">

!!! success "Правильно"

    *[рисунок «Подсказка снизу» — см. ИТС]*
    *[рисунок «Подсказка справа» — см. ИТС]*

!!! failure "Неправильно"

    *[рисунок «Неправильное расположение подсказки» — см. ИТС]*

</div>

###### 3.

Первая буква подписи флажка
должна быть заглавной.

<div class="std-good-bad-pair" markdown="1">

!!! success "Правильно"

    *[рисунок «Подпись с заглавной буквы» — см. ИТС]*

!!! failure "Неправильно"

    *[рисунок «Подпись не с заглавной буквы» — см. ИТС]*

</div>

###### 4.

Подписи у флажков
делайте позитивными
(без отрицания).

<div class="std-good-bad-pair" markdown="1">

!!! success "Правильно"

    *[рисунок «Позитивная подпись» — см. ИТС]*

!!! failure "Неправильно"

    *[рисунок «Подпись с отрицанием» — см. ИТС]*

</div>

Если при этом требуется,
чтобы флажок по умолчанию
был установлен,
у реквизита объекта метаданных
следует установить свойство
`Значение заполнения`
в значение `#!bsl Истина`.

Подпись с отрицанием
следует применять
только в исключительных случаях,
когда это выглядит естественно
или обусловлено историческими причинами.

Например:
`Не показывать это окно`,
`Больше не спрашивать`,
`Недействительный`
(для учета неактуальных пользователей).

###### 5.

Текст подписи
должен быть понятным и кратким.

Не следует делать подпись,
состоящую из двух и более предложений.

###### 6.

Подпись к флажку
определяет только один вариант,
второй остается неявным.

Поэтому текст подписи
следует подбирать так,
чтобы у пользователей
не возникало сомнений,
каким будет второй вариант.

<div class="std-good-bad-pair" markdown="1">

!!! success "Правильно"

    *[рисунок «Однозначная подпись флажка» — см. ИТС]*

!!! failure "Неправильно"

    *[рисунок «Неоднозначная подпись флажка» — см. ИТС]*

</div>

Если такую подпись
подобрать не удается,
лучше использовать радиокнопки,
у которых явным образом
заданы названия вариантов.

<div class="std-good-bad-pair" markdown="1">

!!! success "Правильно"

    *[рисунок «Радиокнопки вместо неоднозначного флажка» — см. ИТС]*

!!! failure "Неправильно"

    *[рисунок «Флажок вместо явного выбора вариантов» — см. ИТС]*

</div>

###### 7.

Если на форме
присутствует группа флажков,
в подписях которых
используется общий текст,
его следует выносить
в заголовок группы.
