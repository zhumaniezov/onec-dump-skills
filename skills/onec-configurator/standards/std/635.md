###### #std635

# Невыбранная картинка

Если в форме есть поле картинки,
которое пользователь может заполнить,
в незаполненном состоянии
оно должно явно показывать
свое назначение.

Например:

- поле для фотографии в карточке сотрудника;
- поле для изображения в справочнике номенклатуры.

<div class="std-good-bad-pair" markdown="1">

!!! success "Хорошо"

    *[рисунок «Оформление невыбранной картинки - хорошо» — см. ИТС]*

!!! failure "Плохо"

    *[рисунок «Оформление невыбранной картинки - плохо» — см. ИТС]*

</div>

Оформляйте невыбранную картинку так:

- указывайте текст
  невыбранной картинки
  (например:
  `Добавить фото`,
  `Добавить изображение`);
- для этого текста
  используйте цвет
  `ТекстНевыбраннойКартинкиЦвет`
  (`RGB: 220,220,220` <span class="std-rgb-dot" style="--std-rgb-color: 220,220,220;" title="RGB: 220,220,220"></span>);
- используйте шрифт
  `ТекстНевыбраннойКартинкиШрифт`
  (шрифт диалогов и меню,
  размер `12`).
