# onec_gen.py dcs check — Проверка СКД

> Справка к `onec_gen.py dcs check`. Основано на документации открытого проекта (лицензия MIT,
> NOTICE.md). Файл создаётся `scripts/sync_engine.py`, вручную не править.


Проверяет структурную корректность Template.xml схемы компоновки данных. Выявляет ошибки формата, битые ссылки, дубликаты имён.


## Параметры

| Параметр     | Обяз. | Умолч. | Описание                                              |
|--------------|:-----:|---------|---------------------------------------------------------|
| TemplatePath | да    | —       | Путь к Template.xml или каталогу макета                 |
| Detailed     | нет   | —       | Подробный вывод (все проверки, включая успешные)         |
| MaxErrors    | нет   | 20      | Остановиться после N ошибок                             |
| OutFile      | нет   | —       | Записать результат в файл                               |

## Команда

```text
python "${CLAUDE_SKILL_DIR}/scripts/onec_gen.py" dcs check -TemplatePath "src/МойОтчёт/Templates/ОсновнаяСхема"
python "${CLAUDE_SKILL_DIR}/scripts/onec_gen.py" dcs check -TemplatePath "Catalogs/Номенклатура/Templates/СКД/Ext/Template.xml"
```

## Проверка по XSD

Порядок элементов, типы и значения дополнительно сверяются с XSD-схемами платформы, если они скачаны в проект. Иначе итоговая строка заканчивается на `XSD not checked: <причина>` — это не «проверено всё». Когда проверка нужна (например, платформа пишет «нарушен порядок следования»), скачай схемы версии формата выгрузки — атрибут `version` в `Configuration.xml` — через XSD-схемы платформы -Versions <версия>` и запусти снова. То же при `[WARN] XSD: no schemas for format <версия>`.

Нарушение: `XSD <версия>, line N: <родитель>/<элемент>: <что не так>`.

- `must come before <X>` — перенеси элемент непосредственно перед `<X>`, содержимое не меняй. `duplicate` — удали повтор. `not allowed in <P>` — элементу здесь не место. Иначе — текст о недопустимом значении.
- `[WARN]` с `(no schemas for <версия>)` — сверено по схемам более новой версии: ориентир, не вердикт.
- Если шаблон ты только что собрал или изменил `dcs build` или `dcs edit`, нарушение — дефект навыка: сообщи о нём пользователю.
