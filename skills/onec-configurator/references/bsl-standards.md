# BSL и стандарты разработки

Полные тексты стандартов ИТС лежат офлайн в `standards/` скилла (права — фирма «1С»):
`onec_std.py show 657 --clause 1` — пункт; `find <слова>` — поиск по теме;
`diag <код>` — какой стандарт стоит за проверкой АПК (`acc:254`), BSL LS или 1C:Code style.
Ссылаясь на стандарт в ответе, указывать номер и пункт (#std657 п.1) и ссылку на ИТС из файла;
при сомнении в актуальности — сверить на ИТС. Ниже — краткая выжимка для частых случаев.


## Источники правил

Различать правило проекта, стандарт ИТС, рекомендацию и локальный компромисс.
Опорные материалы: #std453 «Описание процедур и функций», #std455 «Структура
модуля», #std437 «Оформление текстов запросов», #std469 «Правила создания общих
модулей». Ссылки и границы доступа — `docs/provenance/` репозитория.

Не выдавать предпочтения стороннего автора за ИТС. #std453 требует описания
программного интерфейса, но допускает отсутствие комментария у понятного
внутреннего метода. Точный пункт проверять по тексту, не угадывать по номеру.

## Контекст выполнения

| Контекст управляемой формы | Следствие |
|---|---|
| `&НаКлиенте` | UI; недоступные операции БД переносить на сервер |
| `&НаСервере` | Есть контекст формы; передача её данных имеет стоимость |
| `&НаСервереБезКонтекста` | Явные параметры/результат, без реквизитов формы |
| `&НаКлиентеНаСервереБезКонтекста` | Только API, допустимый в обоих контекстах |

Директивы не заменяют свойства общего модуля. Проверить Сервер, Клиент,
ВызовСервера, ВнешнееСоединение, Глобальный, Привилегированный и повторное
использование. Суффикс имени не доказывает свойство. Для обычных форм
не копировать механически шаблон и данные управляемой формы.

## Модули и методы

- Структуру областей выбирать по виду модуля и проекту. Не перегруппировывать
  весь модуль ради одной правки. В формах группировать по назначению.
- Именовать по смыслу без неоговорённых префиксов и сокращений.
- Описывать параметры, допустимые типы, результат и побочные эффекты интерфейса.
  Для структур/таблиц описывать поля или ссылаться на функцию-конструктор.
- При смене сигнатуры проверить `Экспорт`, все вызовы, события, команды,
  описания оповещений и перехваты расширения.
- Учитывать передачу параметров и `Знач`: это не обещание глубокого копирования
  изменяемого объекта. Изменение переданной коллекции отражать в контракте.
- Различать `Неопределено`, `Null`, пустую ссылку/строку, ноль и Ложь.
  Проверка заполненности не заменяет проверку типа и допустимости значения.

## Частые дефекты

| Ситуация | Что проверить |
|---|---|
| Серверный вызов в цикле формы | Пакет параметров и один вызов при сохранении смысла |
| Чтение реквизитов ссылки в большом цикле | Пакетный запрос или реальный API БСП |
| Передача ТаблицыЗначений клиенту | Доступность/сериализация в целевом клиенте |
| Исключение поймано и проигнорировано | Состояние транзакции, диагностика, честный результат |
| Повторное использование функции | Пользователь/сеанс, изменяемые данные, устаревший кеш |
| Асинхронный метод | Версия, совместимость, продолжение, срок жизни формы |
| Новый API | Наличие в целевой сборке и правильный контекст |

Границы транзакции задавать на уровне операции. Не фиксировать транзакцию,
которой метод не владеет. После ошибки записи не продолжать как при успехе.
Не выдумывать конструкцию `Наконец`. Для сообщения пользователю и технической
диагностики использовать подходящий API проекта, не раскрывать секреты.

## Пример контракта чистой функции

```bsl
// Возвращает сумму строк с положительным количеством.
//
// Параметры:
//  Строки - ТаблицаЗначений - колонки Количество и Цена типа Число.
//
// Возвращаемое значение:
//  Число - сумма без округления и без записи данных.
//
Функция СуммаПоложительныхСтрок(Строки) Экспорт
    Результат = 0;
    Для Каждого СтрокаТаблицы Из Строки Цикл
        Если СтрокаТаблицы.Количество > 0 Тогда
            Результат = Результат + СтрокаТаблицы.Количество * СтрокаТаблицы.Цена;
        КонецЕсли;
    КонецЦикла;
    Возврат Результат;
КонецФункции
```

Правила валютного округления и учёта определяет задача, не этот пример.
