# Расширения конфигурации

## Паспорт расширения

Определить имя, назначение, префикс собственных объектов, версию, режим
совместимости, заимствованные/собственные объекты, ограничения безопасного
режима, порядок взаимодействия с другими расширениями и политику поддержки.
Основная конфигурация и расширение могут иметь одноимённые объекты, но это
разные области файлов. Всегда указывать, какую область меняет операция.

## Заимствование и собственные объекты

Для заимствованного объекта сохранять связь с основной конфигурацией, проверять
контролируемые свойства и доступность нужного изменения в целевой версии.
При изменении базового объекта сверять применимость расширения повторно.
Собственные объекты создавать с префиксом, установленным проектом; префикс
объектов не означает автоматического префикса всех процедур.

Не копировать целый объект типовой в расширение, когда нужен один перехват.
Но и не обещать, что расширением можно изменить любое свойство на любой версии.
Изменение структуры данных расширением требует отдельной платформенной проверки.

## Перехваты BSL

Перед `&Перед`, `&После`, `&Вместо` прочитать точную сигнатуру базового метода,
его контекст, возвращаемое значение и побочные эффекты. Выбрать наименее
инвазивный перехват, сохраняющий штатное поведение. Для `&Вместо` проверить
необходимость, аргументы и результат `ПродолжитьВызов`, а также обработку ошибок.
Не добавлять вызов исходного метода дважды.

Для аннотаций изменения/контроля и новых возможностей расширений проверять
версию платформы. Сигнатуры обработчиков/аннотаций не сочинять по аналогии.
При нескольких расширениях проверить фактический порядок и взаимное влияние.

## Формы и команды

Учитывать дополнения формы расширением, программные изменения и права.
Не редактировать основной XML вместо расширения, если задача относится к CFE.
При заимствовании сохранить идентичность, не присваивать новые UUID существующим
элементам для устранения ошибки применимости.

## Проверка

Проверить загрузку расширения, применимость к точной версии основной
конфигурации, синтаксис соответствующих контекстов, обновление тестовой БД,
сценарий с целевыми правами и повторную выгрузку. Проверка основной конфигурации
сама по себе не доказывает проверку каждого расширения.

Перед обновлением типовой сверить изменения заимствованных объектов и методов.
Не скрывать неприменимость отключением проверки или удалением контролируемых
свойств без анализа причины. Удаление расширения с собственными данными имеет
отдельные последствия; не использовать его как обычный способ отката файлов.
