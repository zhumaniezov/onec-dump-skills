# Изменения

## 2.8.0 — 2026-11-11

- `onec_env.py`: поиск установленных платформ 1С, баз из списка `ibases.v8i` и инструментов;
  подсказка версии по формату выгрузки. `setup` записывает платформу и тестовую базу в
  `.onec/env.json` (базу называет пользователь, скрипт её не выбирает).
- Профили без OneScript, на одном `1cv8`: `profile cf-check | cf-build | cfe-build | epf-build |
  yaxunit`. Ключи `--update-db`, `--list-file` (частичная загрузка), `--check-mode`.
  `changed` составляет список изменённых файлов, `log` показывает журнал платформы.
  Проверено на заглушке платформы; на настоящей 1С не запускалось.
- `pipeline.py`: `${env:ИМЯ}` в команде — пароль берётся из окружения при запуске и не
  попадает в профиль, план и отчёт.
- `ordinary_form.py set-module --apply` сохраняет исходный `Form.bin` в
  `<проект>/.onec/backups/` до записи (`--backup-dir`).
- GitHub Actions: оба набора тестов на Windows и Linux, Python 3.10 и 3.13.
- Исправлено по первому прогону тестов на Windows: `source_edit.py`, `project_context.py` и
  `generator_bridge.py` выводят UTF-8 независимо от кодовой страницы консоли (раньше кириллица
  портилась или скрипт падал); `onec_query.py` печатает пути через `/`, как индекс.
- Руководство: раздел «Сборка и проверка на платформе».

## 2.7.0 — 2026-11-11

- Индекс в 2,4 раза меньше (БСП: 61 → 26 МБ). Повторяющиеся строки связей и процедур (юнит,
  файл, имена объектов и членов) хранятся один раз в словаре `strs`; таблицы `refs` и `procs`
  стали представлениями с прежними столбцами. Скорость запросов и ответы прежние, сборка быстрее.
- После сборки удаляются неиспользуемые строки словаря; если свободных страниц больше четверти,
  выполняется `VACUUM`. Старый индекс при первой сборке пересобирается и сжимается сам.
- Каталог плагинов `.claude-plugin/marketplace.json`: установка
  `/plugin install onec-dump --marketplace zhumaniezov/onec-dump-skills`, обновление через
  `/plugin update`. Руководство и README описывают оба способа установки.

## 2.6.0 — 2026-11-11

- README: рекомендуемая структура папок проекта.

## 2.5.0 — 2026-11-11
